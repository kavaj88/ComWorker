# ComWorker 离线安装说明

## 支持环境

- Linux x86_64：Docker Engine 与 Docker Compose v2。
- Windows 10/11 x86_64：Docker Desktop，必须使用 Linux containers 模式。
- 首版不支持 Windows Server、ARM64 和原生 Windows containers。

客户机器不需要 Python、Node.js、Nginx、PostgreSQL或互联网连接。请至少预留离线包解压后两倍的可用磁盘空间。

## 一键安装

Linux：

```text
chmod +x install.sh comworker.sh
./install.sh
```

Windows：双击 `安装.bat`，也可以在 PowerShell 中运行：

```text
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

安装器会校验文件、导入镜像、生成本机专属密钥、启动服务并显示初始管理员密码。模型 API Key 在安装完成后通过管理端配置。

默认地址：

- 客户端：`http://localhost:3000`
- 管理端：`http://localhost:3081`

如需修改端口，在首次启动前编辑 `.env.example`；已经安装后编辑 `.env` 并执行重启命令。

## 运维

Linux：

```text
./comworker.sh status
./comworker.sh logs
./comworker.sh backup
./comworker.sh restart
./comworker.sh uninstall
```

Windows：

```text
.\comworker.ps1 status
.\comworker.ps1 logs
.\comworker.ps1 backup
.\comworker.ps1 restart
.\comworker.ps1 uninstall
```

普通卸载保留数据库、用户数据和密钥。永久清除需要额外传入 `--purge`（PowerShell 为 `-Purge`）并再次输入 `DELETE`。

## 故障定位

先运行状态和日志命令。常见问题包括 Docker daemon 未启动、Docker Desktop处于 Windows containers 模式、3000/3081 端口已占用或磁盘空间不足。安装脚本可以安全重复执行，不会覆盖已有密钥。

gateway 需要挂载 Docker socket 来创建每用户运行时容器，因此能够操作该服务器 Docker 的管理员等同于拥有宿主机高权限。请限制服务器登录与 Docker 管理权限。
